# 极速高德经纬度水印相机 v6.0.0 (Android 原生双模版 + 微信小程序版 + Web PWA 版)

本项目是专为「**秒开秒拍、光学拍照/极速截屏双模切换、双坐标系切换（默认高德 GCJ-02）、水印内嵌扫码跳高德定位码、图层分离全尺寸无损改水印、微信好友收图直跳同一高德位置**」打造的全端工程。

## v6.0.0 核心升级特性

1. **设置中自由切换「📷 光学拍照模式」与「⚡ 极速截屏模式」**
   - **📷 光学拍照模式（默认）**：真正调用 CameraX `ImageCapture.takePicture`（小程序端调用 `CameraContext.takePhoto`），启用硬件级自动闪光灯测光（`FLASH_MODE_AUTO/ON`）与 ISP 降噪，输出 2560px 高清成片；通过 `UseCaseGroup + ViewPort` 锁定取景框与成片视野 100% 一致。
   - **⚡ 极速截屏模式**：直接定格取景框缓冲帧，0ms 零快门延迟，适合移动抓拍或弱网连续打卡。

2. **纯离线内嵌「扫码跳高德」定位二维码 + 微信小程序好友收图跳高德三重闭环**
   - **内置零依赖 QR 矩阵引擎（`QrCodeGenerator.kt` / `coord_qr.js`）**：无需后端服务器，100% 离线将当前照片的高德 `GCJ-02` 坐标与点位名称编码为标准高容错二维码角标（可在水印设置中独立开关）。
   - **好友收图跳同一高德位置三重闭环**：
     1. **长按图片直接跳**：水印照片发送给微信好友或微信群后，即使被微信压缩抹除 EXIF，好友只需**长按图片识别二维码**，即可直接打开高德地图定位点或唤起小程序进入该坐标；
     2. **小程序带参卡片转发**：在微信小程序内点击「转发给好友」，自动生成以当前水印照为封面的卡片，好友点击卡片直达小程序定位页并调用 `wx.openLocation`（原生 GCJ-02 零偏差）一键拉起高德地图 App 导航；
     3. **导图识位兜底**：在小程序内点击顶部「🔍 识图跳高德」，可从聊天记录或相册选图识别定位码并秒跳高德。

3. **深度 Bug 修复与性能优化**
   - **防二次偏移与逆地理编码纠偏**：智能区分硬件 `GPS_PROVIDER`（WGS-84）与国产 ROM 网络定位源，防止二次加偏；`Geocoder` 优先使用 `GCJ-02` 坐标解析国内街道门牌；快门异步寻优等待窗口升级为 `1100ms`（完整覆盖 800ms GPS 周期）。
   - **外业增强遥测要素**：新增实时 **海拔高程（Altitude）** 与 **电子罗盘方位角（Azimuth）** 开关。
   - **真 `ColorMatrix` 硬件实时滤镜与画笔池化**：取景器实时渲染真黑白/暖阳/清冷滤镜（所见即所得）；`WatermarkRenderer` 采用 `ThreadLocal` 画笔池化消除主线程每帧 GC；导入系统原相机竖屏照片自动识别 EXIF `Orientation` 旋转扶正；删除照片同步清理系统 `MediaStore`。

## 目录结构

- `app/`：Android 原生工程（Kotlin + Jetpack Compose + CameraX + ExifInterface）
- `wechat-miniprogram/`：零依赖原生微信小程序工程（直接导入**微信开发者工具**即可真机运行）
- `web-pwa/`：单文件离线 Web PWA 预览版（支持全部 5 款模板、定位二维码与双模切换）
