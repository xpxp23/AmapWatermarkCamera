# 极速高德经纬度水印相机 v7.0.0 (Android 原生双模版 + 微信小程序版 + Web PWA 版)

本项目是专为「**秒开秒拍、光学拍照/极速截屏双模切换、高德 160×160 矢量缩略地图画中画（Mini-Map）、NTP 授时 + SHA-256 外业防伪验真、高德 GCJ-02 零偏差定位码、图层分离全尺寸无损改水印**」打造的全端工程。

## v7.0.0 重大升级与全量修复

1. **🗺 高德静态矢量缩略地图（Mini-Map 160×160px）画中画水印**
   - 在「工程巡检卡片（模板 1）」与「经纬网格测绘（模板 2）」中，支持在**水印卡片左侧内嵌**或**画面左上角独立悬浮**一块 `160×160px` 的高德高清矢量缩略地图。
   - 实时绘制周边次干道/主干道矢量路网、水系/绿地斑块、经纬测绘十字丝、GPS 精度圈、**电子罗盘朝向扇形（Azimuth View Cone）**与中心高德红针，直观呈现点位与周边道路方位关系。

2. **🛡 外业防伪验真机制（防篡改模式）**
   - 针对工程隐蔽验收、保险查勘、物业巡检场景，新增可选的「**外业防篡改验真模式**」：
     - **三重真实时间校准**：自动联网校准 NTP 授时服务器（`ntp.aliyun.com` / `cn.pool.ntp.org`）、HTTPS 权威响应头与硬件 GPS 卫星原子钟，锚定系统单调时钟（`elapsedRealtime`），彻底杜绝通过修改手机系统时间作弊。
     - **坐标与时间硬件锁定**：开启防篡改模式后，自动禁止手动偏移经纬度坐标与修改拍摄时间。
     - **SHA-256 密码学签名双写**：将 `GCJ-02 坐标 + 秒级真实时间 + 地点简称` 计算 FIPS 180-4 SHA-256 签名摘要，同时写入**水印视觉印章**、**二维码跳转参数（`&sig=...&ts=...`）**与 **JPEG EXIF `UserComment`/`ImageDescription`**，扫码即可一键核验照片是否经过二次篡改。

3. **五大核心痛点彻底根治**
   - **二维码 100% 秒识别**：修复了 `0x77C4` 格式信息位（Format Information）高低位反转 Bug，将 QR 引擎从 Version 5 扩容至 **Version 1~9（最高 229 字节）**，加入 UTF-8 多字节边界保护与 ISO 标准 **4 模块白色静区**，微信长按、高德扫码与系统相机 100% 秒识别。
   - **5 款专业模板视觉彻底差异化**：微信小程序端、Android 端与 Web PWA 端统一实现全部 5 款独立视觉架构模板（经典大字时间、工程巡检卡片、经纬网格测绘、极简胶片底栏、外业标准台账）。
   - **相册 UI 优雅重构与层级防穿透**：解决小程序 `<camera>` 与 `<cover-view>` 原生组件穿透压盖相册弹窗、顶部按钮与微信胶囊重叠、空相册布局塌陷等问题；新增横向缩略图切换条与空相册引导页。
   - **告别写死“小庄村”，三级自动逆地理编码**：移除所有硬编码“小庄村”默认值，内置系统 Geocoder + 在线逆地理编码 + 离线城市网格推演三级引擎，并提供**周边高德 POI 候选词一键点选**。
   - **长地名智能双行折行与防遮挡**：所有 Canvas 模板均严格扣除右侧二维码安全区（`qrSpace = 180px`），长地点与详细地址支持自动折为 2 行或安全省略，绝不触碰或遮挡右侧二维码。

## 目录结构

- `app/`：Android 原生工程（Kotlin + Jetpack Compose + CameraX + ExifInterface）
- `wechat-miniprogram/`：零依赖原生微信小程序工程（直接导入**微信开发者工具**即可真机运行）
- `web-pwa/`：单文件离线 Web PWA 预览版（支持全部 5 款模板、160×160 高德缩略图、SHA-256 防伪验真与定位二维码）
